🐍 Termux Snake

A simple Snake game made with Python that you can play right in your Termux terminal!

Eat the food, grow your snake, and try to get the highest score without hitting the walls or your own tail. Have fun! 🎮

📥 Installation

Open Termux and run these commands:

pkg update
pkg install python git
git clone https://github.com/zaydzaydfarhat-blip/termux-snake.git
cd termux-snake
python game.py

🎮 Controls

- Arrow keys or WASD — Move the snake
- Q — Quit the game

✨ Features

- Classic Snake gameplay
- Food that makes your snake grow
- Score tracking
- Wall and self-collision detection
- Runs in the terminal using Python's built-in "curses" module

🛠️ Requirements

- Android with Termux
- Python 3
- Git

No extra Python packages are needed.
